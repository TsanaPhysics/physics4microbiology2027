## 🧭 วิธีใช้งานร่วมกับหนังสือเรียน 3D AR บนสมาร์ทโฟน (iOS / Android)

### ขั้นตอนที่ 1: การเปิดใช้งาน GitHub Pages (ทำครั้งเดียวสำหรับผู้ดูแลระบบ)
1. ไปที่หน้า Repository [`https://github.com/TsanaPhysics/physics4microbiology2027/settings/pages`](https://github.com/TsanaPhysics/physics4microbiology2027/settings/pages)
2. ในหัวข้อ **Build and deployment (Source)** เลือก **Deploy from a branch**
3. เลือกกิ่ง **`main`** และโฟลเดอร์ **`/(root)`** จากนั้นกด **Save** (รอประมาณ 1 นาที เว็บแอป HTTPS จะพร้อมใช้งานทั่วโลก)

### ขั้นตอนที่ 2: การเปิดแอปและติดตั้งเป็น Smartphone App (PWA)
* **วิธีเข้าใช้งานทันที:** ใช้กล้องมือถือสแกน QR Code ประจำบทในหนังสือเรียน หรือเปิดลิงก์ `https://tsanaphysics.github.io/physics4microbiology2027/ar.html`
* **วิธีติดตั้งเป็นไอคอนแอปบนหน้าจอมือถือ (ไม่ต้องผ่าน App Store):**
  * **iPhone / iPad (Safari):** แตะปุ่ม **แชร์ (Share)** ด้านล่าง → เลือก **"เพิ่มไปยังหน้าจอโฮม (Add to Home Screen)"**
  * **Android (Chrome):** กดปุ่ม **"📱 แอปมือถือ & วิธีใช้ผ่าน GitHub"** ด้านบนของหน้าเว็บแอป แล้วกด **"📲 ติดตั้งแอปสมาร์ทโฟน (Install AR App)"**

### ขั้นตอนที่ 3: การส่องมาร์กเกอร์ ArUco ในหนังสือเรียน และการควบคุมโมเดล 3D สุดล้ำ
1. **โหมด 🧊 Hyper-3D Studio (ค่าเริ่มต้น):** หมุนดูเครื่องมือวิทยาศาสตร์ 3 มิติรอบทิศทาง 360° ด้วยวัสดุสมจริง (PBR + Procedural Studio HDR Reflections)
2. **โหมด 📷 ส่องหนังสือ AR (ปุ่มอัญมณีสีเขียวตรงกลางล่าง):**
   * กดปุ่ม **📷 ส่อง AR** เพื่อเปิดกล้องหลังของสมาร์ทโฟน
   * นำกรอบเล็งเลเซอร์ส่องไปที่ **มาร์กเกอร์ ArUco (ID 0 ถึง ID 11)** ในหนังสือเรียน (หรือเปิดหน้า `markers.html` บนจอคอมพิวเตอร์แล้วใช้มือถือส่อง)
   * เมื่อตรวจพบมาร์กเกอร์ โมเดล 3 มิติประจำบทจะลอยขึ้นมาเหนือกระดาษพร้อมเสียงล็อกเป้าหมาย!
3. **ฟีเจอร์แสดงผลสุดล้ำภายในแอป:**
   * **🔍 แยกชิ้นส่วน X-Ray (Exploded View):** กดเพื่อแยกชิ้นส่วนภายในเครื่องมือ (เช่น ลูกสูบไมโครปิเปต, แผ่นกรอง HEPA, ฝาหม้อนึ่ง Autoclave, หัวเลนส์ 100x)
   * **🏷️ ป้ายโฮโลแกรม 3D (3D Callout Badges):** ป้ายชี้ส่วนประกอบสำคัญลอยในฉาก 3 มิติ
   * **📈 กราฟฟิสิกส์เรียลไทม์ 60 FPS (Live Oscilloscope):** แสดงกราฟแปรผันตามการเลื่อนสไลเดอร์ในแถบ `DATA` และ `CTRL`
   * **🔊 AI บรรยายเสียงภาษาไทย:** กดปุ่ม **AI เสียง** เพื่อฟังเสียงอธิบายหลักการทางฟิสิกส์และจุลชีววิทยาของแต่ละบท
