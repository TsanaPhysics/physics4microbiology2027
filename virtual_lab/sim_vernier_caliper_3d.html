ทดลองปิดปากวัดสุด (Zero) เพื่อสังเกตตำแหน่งขีด 0 ของสเกลเวอร์เนียร์เมื่อมีค่าความคลาดเคลื่อนศูนย์

📘 หลักการอ่านค่าเวอร์เนียร์แคลิปเปอร์ (How to Read a Vernier Caliper)

ขั้นตอนการอ่านค่า 3 ขั้นตอนมาตรฐาน

  1. อ่านค่าสเกลหลัก (Main Scale - MS): ดูขีดสเกลหลัก (หน่วย mm) ที่อยู่ทางซ้ายมือหรือตรงกับขีด 0 ของสเกลเวอร์เนียร์
  2. อ่านค่าสเกลเวอร์เนียร์ (Vernier Scale - VS): สังเกตหาขีดของสเกลเวอร์เนียร์ที่ตรงกับขีดใดขีดหนึ่งบนสเกลหลักมากที่สุด แล้วนำลำดับช่องคูณด้วยความละเอียด (Least Count เช่น 0.05 mm)
  3. ชดเชยค่าความคลาดเคลื่อนศูนย์ (Zero Error - ZE): ก่อนวัดให้เลื่อนปิดปากวัดจนสนิท หากขีด 0 เหลื่อมไปทางขวาเป็นค่าบวก (+ZE) หรือทางซ้ายเป็นค่าลบ (-ZE) ให้นำมาลบออกตามสูตร:
ค่าที่วัดได้จริง = MS + (ลำดับขีดที่ตรงกัน × ความละเอียด) − Zero Error
1. ปากวัดนอก (Outside Jaws)

ใช้วัดความกว้าง ความหนา หรือเส้นผ่านศูนย์กลางภายนอก (OD) โดยวางชิ้นงานแล้วเลื่อนปากวัดเข้าหนีบ

2. ปากวัดใน (Inside Jaws)

เขี้ยววัดด้านบนใช้วัดเส้นผ่านศูนย์กลางภายในท่อหรือร่อง (ID) โดยสอดเขี้ยวเข้าด้านในแล้วถ่างออกจนชนผนัง

3. ก้านวัดลึก (Depth Rod)

วางปลายรางสเกลหลักทาบปากหลุม แล้วเลื่อนก้านวัดความลึกยื่นลงไปแตะก้นหลุมพอดี
